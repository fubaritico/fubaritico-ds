# A08:2025 — Software & Data Integrity Failures

OWASP Top 10 #8. Code and artefacts trusted without verifying their integrity.

**In this repository**: the integrity of what is **published** — the tarballs on GitHub Packages, the tags,
the generated wrappers.

## Checklist

### High

#### OWASP-A08-001: Release from an unverified state
- **Where**: `release.yml`, the `/release` skill, `lerna.json`
- **Check**: publication runs in CI from a tag after the gate (type-check, lint, test, build) — never from a
  developer machine with a dirty tree

#### OWASP-A08-002: Hand-edited generated artefact
- **Where**: `packages/stencil/dist/{react,angular}/**`, `**/components.d.ts`, `packages/tokens/dist/**`
- **Check**: regenerated by the build, not edited (an edit is lost or diverges from the source)

### Medium

#### OWASP-A08-003: Hooks that can be skipped silently
- **Where**: `.husky/*`, root `package.json` (`prepare: husky`)
- **Check**: pre-commit runs the gate, commit-msg runs commitlint; CI repeats the gate (a `--no-verify`
  commit is still caught)

#### OWASP-A08-004: Remote script or style without integrity
- **Where**: Storybook preview head (`.storybook/*`), HTML files
- **Check**: no CDN `<script>`/`<link>` without `integrity`; fonts and assets served from the package
